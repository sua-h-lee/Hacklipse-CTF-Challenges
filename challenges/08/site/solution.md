# 풀이 (출제자/검수자용 · 배포 금지)

**정답 장소:** 비스타블루 베이커리카페
**플래그:** `HKL{비스타블루베이커리카페}`

## 의도한 풀이 경로

1. **메타데이터 확인 (막다른 길인 것을 확인하는 단계)**
   ```
   exiftool cafe.png
   ```
   → GPS 없음. PNG이고 EXIF 자체가 없으므로 "메타데이터로는 못 푼다"를 빠르게 확정하고
   이미지 분석으로 넘어가야 한다. (배포본은 `Software=Snipaste`, `User Comment=Screenshot`
   tEXt 청크까지 제거해서 출처 흔적도 지웠다.)

2. **이미지에서 단서 추출**
   - 설명문: "공기가 짭짤했다" → **바닷가**
   - 설명문: "작년 10월", 햇빛 각도가 낮고 길다 → 늦은 오후
   - 사진: 넓은 **잔디밭**, 흰색 **파라솔/셰이드 세일** 다수, **야외 테라스 좌석**
   - 사진: 좌측 상단 **유리/금속 마감의 현대식 건물 모서리** → 신축 대형 카페
   - 사진: 수평선이 보이고 그 앞으로 낮은 지형 → 섬이 아니라 완만한 해안선
   - 음료: 아이스 라떼 + 붉은 그라데이션 에이드 (시그니처 메뉴 추정)

   → 종합: "바다 보이는 잔디밭 있는 대형 베이커리 카페"

3. **검색**
   - 지도 앱 키워드 검색: `바다뷰 베이커리 카페`, `잔디 바다 카페`, `오션뷰 대형카페`
   - 또는 **리버스 이미지 서치** (구글 렌즈 / 네이버 스마트렌즈 / Yandex)
     → 동일 장소를 찍은 블로그·인스타 후기 사진이 매칭됨
   - 후보 카페의 플레이스 사진과 **파라솔 배치·잔디·건물 형태**를 대조해 확정

4. **검증**
   네이버 지도 / 카카오맵 플레이스에 등록된 사진 중 같은 각도(테라스 → 잔디 → 바다)
   사진을 찾아 파라솔 위치와 건물 모서리가 일치하는지 확인.

## 채점 주의사항

- 정식 상호가 "비스타블루 베이커리카페"이므로 **띄어쓰기 변형**이 반드시 나온다.
  관대 채점을 하려면 CTFd에 추가 플래그를 등록하거나 아래 정규식을 쓸 것.
  ```regex
  (?i)^HKL\{\s*비스타[\s_-]*블루([\s_-]*베이커리)?([\s_-]*카페)?\s*\}$
  ```
  영문 표기까지 받으려면:
  ```regex
  (?i)^HKL\{\s*vista[\s_-]*blue([\s_-]*bakery)?([\s_-]*cafe)?\s*\}$
  ```
  (구분자로 공백뿐 아니라 `_`, `-`도 받는다 — `vista_blue_cafe` 같은 입력이 실제로 들어온다.)
- 문제 설명문의 "예시 형식"은 **실제 정답과 무관한 가짜 상호**(`서울숲가든카페`)를 써서
  접미사("베이커리카페")가 새어나가지 않게 했다.
