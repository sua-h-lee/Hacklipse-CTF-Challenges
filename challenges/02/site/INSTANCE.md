# 2번 문제 인스턴스 운영

랩 서버에서 이 폴더를 빌드합니다.

```sh
sudo docker build -f Dockerfile.instance -t hkl-member:pilot .
```

랩 러너와 플랫폼에 같은 HTTPS 주소를 CTF_MEMBER_ORIGIN으로 설정합니다. HTTPS 프록시는 이 주소에서 받은 요청을 랩 서버의 127.0.0.1:9012로 전달합니다. 플랫폼과 러너 간 9011 관리 API는 기존 내부 경로를 사용합니다.

각 인스턴스의 SQLite 파일과 PHP 세션은 해당 컨테이너의 임시 디렉터리에 저장합니다. 주소는 개인 접속 링크이며 종료 또는 30분 만료 시 사용할 수 없습니다.

현재 게시판 파일에는 플래그 제공 로직이 없습니다. 참가자가 제출할 정답은 플랫폼 채점 설정에서 관리합니다.
